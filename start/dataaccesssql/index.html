Data Access - SQL

If you want to pull the data into your existing workflows, you can connect to our online database directly. Use the following credentials to do so:

  • Hostname: 34.210.173.143
  • Port: 3306
  • Adapter: MariaDB
  • Database: 2025.1 (or any supported release like 2022.1, 2021.1)
  • Username: reader
  • Password: gazeofraccoons

You can then access the DB in your programming language of choice:

  • Python
  • R DBI
  • JavaScript/Deno 
import pymysql

conn = pymysql.connect(
    host='34.210.173.143',
    port=3306,
    database='2025.1',
    user='reader',
    password='gazeofraccoons'
)

cursor = conn.cursor()
cursor.execute("SELECT dataset_name, shortcite FROM datasets LIMIT 5")
results = cursor.fetchall()
conn.close()
library(DBI)
library(RMariaDB)

con <- dbConnect(
  MariaDB(),
  host = "34.210.173.143",
  port = 3306,
  dbname = "2025.1",
  username = "reader",
  password = "gazeofraccoons"
)

datasets <- dbGetQuery(con, "
  SELECT dataset_name, shortcite, COUNT(DISTINCT subject_id) as n_subjects
  FROM datasets d
  JOIN administrations a ON d.dataset_id = a.dataset_id
  GROUP BY d.dataset_id, dataset_name, shortcite
")

head(datasets)
dbDisconnect(con)
